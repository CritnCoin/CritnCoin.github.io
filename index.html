Featured Project

Descent Into Darkness

A dark fantasy dungeon extraction RPG centered on brutal underground expeditions, dangerous loot decisions, party survival, tense combat, and the constant pressure of deciding when to push deeper or escape.

The project is currently in early development, with focus on core gameplay direction, visual identity, interface design, combat feel, dungeon atmosphere, and progression systems.

Development Roadmap

Current Build Direction

The current goal is to establish the project identity first: visual tone, core gameplay loop, player fantasy, UI direction, and public portfolio presentation.

Get in Contact
Phase 01

Foundation

Define world tone, gameplay pillars, combat direction, dungeon identity, extraction loop, class fantasy, and public project branding.

Phase 02

Prototype

Build early movement, interaction, inventory, dungeon rooms, enemy encounters, loot pickup, extraction logic, and basic UI feedback.

Phase 03

Vertical Slice

Create a small playable slice with a complete dungeon route, combat test, loot flow, escape condition, menu polish, and public screenshots.

Phase 04

Content Pass

Add more rooms, enemies, items, equipment types, environmental hazards, dungeon events, merchant systems, and player progression.

Phase 05

Public Dev Log

Post development updates, screenshots, design notes, problems solved, build milestones, and lessons learned while the project grows.

Phase 06

Playable Release

Prepare a small public demo or private test build once the core loop feels stable, readable, tense, and worth showing.
