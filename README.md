# CritNCoin Studios — Website

This repository is the official **CritNCoin Studios** website, hosted with GitHub Pages.

CritNCoin Studios is an independent **dark fantasy game development studio**. This
site is the studio's game development **portfolio and project hub**, featuring its
flagship project — *Descent Into Darkness*, an old-school dungeon extraction RPG of
high-risk loot survival and torchlit dungeon delving.

## What's here

- **Home** — studio landing page and branding
- **Projects** — portfolio archive
- **Descent Into Darkness** — the main game project, with Dev Log, Roadmap, and Screenshots
- **Research** — design, combat, UI/UX, pipeline, and technical notes
- **Resume** — game development resume (work in progress)
- **Contact** — studio contact hub

## Tech

Plain, hand-written **HTML, CSS, and JavaScript**. No frameworks, no build tools,
no npm. The entire site uses a single stylesheet (`css/style.css`) and a single
minimal script (`js/main.js`).

## Preview locally

From the repository root, start any static file server, for example:

```bash
# Python 3
python -m http.server 8000
```

Then open <http://localhost:8000/> in your browser. (Using a local server — rather
than opening files directly — ensures the clean directory links like `/projects/`
resolve correctly.)
