Road Map

The full development path — from concept lock and prototype through combat, dungeons, loot, trade, and the dungeon doors finally opening to the public.

◆

Phase 01Concept Lock Done

Lock the project identity, core fantasy, tone, target gameplay loop, and public-facing direction.

  • Core fantasy & tone locked — grim torchlit dungeon extraction
  • Target gameplay loop defined: descend, gather, decide, escape
  • Public-facing wording and studio direction set

Phase 02Website / Portfolio Foundation In Progress

Build the public project hub, roadmap, dev log, screenshot page, and branding structure.

  • Project hub, roadmap, dev log, and gallery pages
  • Branding, fonts, and gothic interface styling

Phase 03Prototype In Progress

Build the earliest playable test with movement, interaction, a basic dungeon space, and extraction-loop proof.

  • Player movement & interaction
  • First playable dungeon room
  • Extraction-loop proof of concept

Phase 04Combat In Progress

Add first-pass melee, blocking, hit feedback, enemy behavior, damage rules, and combat readability.

  • First-pass melee, blocking, and hit feedback
  • Enemy behavior and clear threat tells
  • Damage rules and combat readability

Phase 05Level Building — Dungeon Pass Planned

Build dungeon rooms, corridors, entrances, exits, hazards, lighting, encounter spaces, and route flow.

  • Rooms, corridors, entrances, and exits
  • Hazards, lighting, and encounter spaces
  • Route flow and extraction points

Phase 06Loot & Equipment Pass Planned

Add weapons, armor, valuables, rarity, item pickups, gear identity, and dungeon reward structure.

  • Weapons, armor, and valuables
  • Rarity tiers and item pickups
  • Gear identity and dungeon reward structure

Phase 07Inventory Mechanics Planned

Add inventory slots, item movement, item inspection, equipment handling, dropping items, and loot pressure.

  • Inventory slots and item movement
  • Item inspection and equipment handling
  • Dropping items and carry-weight loot pressure

Phase 08Merchant Mechanics Planned

Add merchant UI, buying, selling, item values, basic economy, and safe-zone preparation.

  • Merchant UI with buying and selling
  • Item values and a basic economy
  • Safe-zone preparation between runs

Phase 09Trade System Planned

Add player-facing trade flow, item exchange rules, trading restrictions, and economy balance testing.

  • Player-facing trade flow and item exchange
  • Trading restrictions and safeguards
  • Economy balance testing

Phase 10UI Polish Planned

Improve menus, buttons, tooltips, readable item cards, settings, accessibility, and gothic interface styling.

  • Menus, buttons, tooltips, and item cards
  • Settings and accessibility options
  • Consistent gothic interface styling

Phase 11Playtest Build Planned

Prepare a controlled test build with known goals, test notes, feedback tracking, and bug reports.

  • Controlled build with clear test goals
  • Feedback tracking and bug reports

Phase 12Public Demo — Beta Test Planned

Release a small public or limited demo once the core dungeon loop feels stable and worth showing.

  • Small public / limited demo build
  • Released once the core loop feels stable

Phase 13Store Page / Download Page Planned

Prepare screenshots, trailer materials, description copy, download links, build notes, and public release structure.

  • Screenshots, trailer materials, and description copy
  • Download links and build notes
  • Public release structure

Beyond the Core Path

Future Systems Under Research

Deeper systems being studied for the long descent. These are exploratory — prototyped and tested before any promise is made.

ResearchModular Dungeon Generation Research

Test room modules, layout rules, route generation, spawn distance, extraction placement, and how map size changes the pacing of a run.

ResearchLobby Size & Dungeon Scale Testing Research

Experiment with player counts, dungeon size, spawn separation, and encounter pacing to avoid instant fights while still keeping the dungeon dangerous.

PlannedBackpack & Carry Capacity Systems Planned

Explore backpack tiers, crafted storage upgrades, rare carrying items, and inventory choices that support looting without removing pressure.

PlannedPvE Loot Reward Pass Planned

Improve monster rewards so creature encounters feel worth engaging with and support the dungeon economy.

PlannedLore & Puzzle Room Pass Planned

Add hidden story fragments, environmental puzzle rooms, secret paths, and discovery-based rewards.

PlannedLighting & Darkness Pass Planned

Tune darkness, torchlight, visibility, readability, and atmosphere so the dungeon feels grim without becoming frustrating.

ExperimentalExploration Mode Research Experimental

Study larger dungeon formats built around longer exploration, deeper routes, more room variety, and slower-burn PvPvE encounters.

Legend

Done   In Progress   Planned   Research   Experimental

Roadmap items are subject to change as systems are prototyped, tested, cut, rebuilt, or improved.
